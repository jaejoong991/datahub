1. Gambaran Umum

Ecommerce Data Hub adalah aplikasi dashboard internal web yang menampilkan data penjualan, keuangan, dan stok dari Shopee secara otomatis. Aplikasi bersifat read-only — tidak mengubah data di Shopee.

📊 Sales

Ringkasan penjualan, tren harian, produk terlaris.
Sales Finance Admin

💰 Finance

Rincian biaya per order, payout released & pending, fee breakdown.
Finance Admin

📦 Warehouse

Stok produk, daftar kirim, peringatan stok rendah. Tanpa nilai uang.
Sales Gudang Admin

⚙️ Admin

Status sinkronisasi, token Shopee, kelola pengguna.
Admin

Catatan: Perkiraan pengguna < 20 orang. Tidak ada akses dari luar organisasi. Setiap pengguna hanya melihat data sesuai perannya.

4. Ringkasan Penjualan (Sales)

📊 4 KPI Cards

Bruto penjualan, jumlah order, rata-rata nilai order, item terjual. Masing-masing dengan delta % vs periode sebelumnya.

📈 Tren Harian Chart

Bar chart (Recharts) — bruto per tanggal WIB. Tooltip interaktif format IDR.

🏆 Produk Terlaris

Tabel top produk berdasarkan qty terjual. Pagination server-side.

📅 Date Range Picker

Filter periode. Preset: 7 hari, 30 hari, bulan ini, bulan lalu. Input manual.

Struktur halaman:

  • Toolbar → KPI cards → 2 column grid (chart + tabel) → info note
  • Role warehous tetap bisa lihat tapi kolom uang diganti "—"
  • Data dummy: bruto Rp 78,6 jt, 606 order, 1.247 item terjual

5. Keuangan (Finance)

💰 Dual Panel: Released & Pending

Panel terpisah tegas — tidak pernah dijumlahkan. Dana released = sudah cair, pending = belum.

📋 Rincian Per Order

Bruto, komisi, biaya layanan, admin, voucher penjual, refund, payout bersih. Pagination.

🔍 Filter & Basis Tanggal

Search order number. Toggle filter berdasarkan tanggal order atau tanggal payout.

📊 Fee Breakdown

Ringkasan komponen biaya — nominal + persentase terhadap bruto. Alert jika other_fee membesar.

✅ Released (1089)

Total fee: Rp 56,2 jt

Aturan penting:
  • Pendapatan bersih hanya dari tabel settlement — tidak pernah dari order
  • Pending order: fee fields = null (bukan Rp 0), render sebagai "—"
  • Identity: gross − all fees − refund = net_payout — alert jika tidak balance

6. Stok & Produk

📊 KPI

Total SKU aktif, SKU stok rendah, SKU habis. Label jenis stok (mis. "Stok tersedia").

SKU, nama, harga, stok, ambang, kondisi — dengan pagination server-side.

⚠️ Condition Badges

8. Status Sinkronisasi (Admin)

🔑 Otorisasi Token

Info partner_id, masa berlaku access & refresh token. Tombol "Otorisasi ulang toko".

🔄 Job Sinkronisasi

Tabel: data, terakhir sukses, status (Normal/Gagal n×), tombol sync manual.

✅ Rekonsiliasi

7 hari terakhir. Cocok vs Selisih + tombol proses ulang.

📊 Statistik API

Panggilan API 24 jam, kedalaman antrean, job gagal.

ProductTiap 6 jamSemua produk & varian

Pesan error ditampilkan apa adanya — admin perlu teks persis untuk melapor ke Shopee.

9. Pengguna (Admin)

👥 Daftar Pengguna

Tabel: nama, email, Sales Finance Gudang Admin, status aktif/nonaktif, tanggal dibuat.

➕ Tambah/Edit

Modal form: nama, email, password (opsional saat edit), pilih peran.

🚫 Nonaktifkan

Konfirmasi dialog. Pengguna nonaktif tidak bisa login. Bisa diaktifkan kembali.

🔒 Admin Only

Menu "Pengguna" hanya muncul di sidebar jika role = admin.

Akses: Admin only. Menu tidak dirender untuk role lain.

Fitur Lintas Halaman

📅 Date Range Picker

Input manual + preset. Ada di semua halaman laporan.

📄 Pagination

Server-side. Pilih 10/25/50/100 baris. Navigasi halaman.

📊 Chart Recharts

Bar chart interaktif. Tooltip format IDR. Skeleton loading.

🚦 States Lengkap

Loading skeleton, error with retry, empty state dengan pesan.

🔒 Server-side RBAC

Menu, kolom, data — semua difilter di server. Frontend cuma render.

✅ Freshness Indicator

"Sinkron N menit lalu" setiap halaman. Kuning jika basi.
